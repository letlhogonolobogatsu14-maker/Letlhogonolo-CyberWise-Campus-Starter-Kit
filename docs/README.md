CyberWise Campus Starter Kit
Overview: This resource provides Cybersecurity Awareness for university students. Focuses on identifying threats and protecting themselves.
Aim:Teach students how to identify phishing, create strong passwords and enable Multi-Factor Authentication (MFA) to keep their accounts secure. They will also learn how to report security incidents.
Content:Phishing awareness guide, Account security guide, Cybersecurity checklist for students, Incident report template.
How to use:Read guides, implement the recommendations, complete the checklist and write an example of a security incident using the incident report template.
Security notice:Do NOT include passwords, authentication tokens, sensitive information from the university or real incident reports from students.
Summary:This resource teaches students how to be aware of cybersecurity to reduce risk and keep their devices and accounts secure.
